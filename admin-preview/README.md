# Token Management Admin Dashboard — Frontend

این پروژه فقط فرانت‌اند پنل مدیریت است و بک‌اند یا دیتابیس سروری همراه آن نیست.

## فناوری‌ها
- React 19 و TypeScript
- Vite 7 برای اجرای توسعه و ساخت خروجی
- Tailwind CSS 4 برای استایل‌دهی
- ذخیره‌سازی فعلی اطلاعات در `localStorage` مرورگر

## اجرا
1. Node.js نسخه LTS را نصب کنید.
2. در ترمینال وارد پوشه پروژه شوید.
3. دستور `npm install` را اجرا کنید.
4. برای اجرای توسعه: `npm run dev`
5. آدرس محلی نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.
6. برای ساخت نسخه انتشار: `npm run build`
7. خروجی انتشار در پوشه `dist/` ساخته می‌شود.

## ساختار اصلی
- `src/main.tsx`: نقطه ورود React و بارگذاری CSS
- `src/App.tsx`: پوسته اصلی پنل، منوها، وضعیت برنامه و عملیات داده
- `src/pages/`: صفحات داشبورد، خزانه، فروش، حسابداری و پشتیبانی
- `src/components/`: اجزای رابط کاربری مشترک و لوگو
- `src/data.ts`: مدل‌ها، انواع TypeScript، داده‌های اولیه و توابع محاسباتی
- `src/hooks.ts`: هوک‌های رابط کاربری و ذخیره/خواندن اطلاعات مرورگر
- `src/index.css`: طراحی بصری، رنگ‌ها، واکنش‌گرایی و انیمیشن‌ها
- `index.html`: قالب HTML اصلی و تنظیم زبان فارسی و راست‌چین

## نکته مهم درباره اتصال به سرور
در نسخه فعلی، داده‌ها با `localStorage` ذخیره می‌شوند؛ یعنی داده‌ها به همان مرورگر و همان دستگاه وابسته‌اند و بین کاربران یا دستگاه‌ها همگام نمی‌شوند. برای استفاده واقعی چندکاربره باید API بک‌اند، احراز هویت و دیتابیس اضافه شود و توابع خواندن/نوشتن داده در `App.tsx` و `hooks.ts` به API متصل شوند.
